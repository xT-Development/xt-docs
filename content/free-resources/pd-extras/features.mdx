# Features

### Police Tools

* Night vision goggles w/ thermal toggle
* Slimjims - Easier "lockpicks" for PD only

### Police Certifications

* Granted / revoked by officers w/ access to boss menus
* Menu / command to view your own certs
* Can be used as checks for accessing armory items, vehicles, boats, and helis

### Boss Menus

* View officers info (rank, certifications)
* Change officers ranks
* Grant / revoke certifications
* View officers by specific rank

### Evidence Lockers

* Create / open evidence lockers at specific locations, or use a command nearby to open evidence lockers
* PD "trash can" that will regularly wipe (interval set in config)

### Armory

* Quick Restock - Set certain items and max amounts for a "quick refill"
* Rank / cert checks for each item
* Categorized items. Weapons, ammo, medical items, & tools

### Garages, Boats & Helis

* Rank & certification checks for each vehicle

### Duty Blips

* Blip sprite changes based on vehicle
* Different blip colors for each LEO job

### Police Commands

* View your own certs
* Send players a fine
