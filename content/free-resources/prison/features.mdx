# Features

### General Features

* Send players to jail
* Check jail time / check-out of prison
* Remove jobs from players when sent to prison
* Canteen ped providing players with 1 food and 1 drink item
* Doctor ped providing players with check-ups for basic heals/revives
* Auto apply prison outfits and restore outfits on exit
* Configurable to work with [xt-prisonjobs](https://store.xthrasherrr.dev/resources/5226873)

### Prison Roster

* View a list of people currently in prison
* Control their jail time
* Unjail them

### Prison Breaks

* Global statebags for prison break alarms and all prison gate terminals
* isBusy and isHacked states for gate terminals
* Configurable function to use any minigame for hacking the gate terminals
* Different random chances alarm is enabled for failed & successful hacking attempts
* Different random chances to remove items for failed & successful hacking attempts
* Minimum required police check for prison breaks
* Cooldowns on all gate terminals

### Configuration

* Multiple open functions for integrating necessary 3rd party resources
* Dispatch
* Emotes
* Heal Player
* Reset Clothing
* Prison Break Minigame
