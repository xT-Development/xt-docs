# Installation & Usage

## Usage

### Check Duty State

<Tabs items={['Client', 'Server']}>
<Tabs.Tab>

```lua filename="client.lua"
local duty = LocalPlayer.state.onDuty
```

</Tabs.Tab>
<Tabs.Tab>

```lua filename="server.lua"
local duty = Player(source).state.onDuty
```

</Tabs.Tab>
</Tabs>

### Toggle & Set Duty

Both exports are **client only**.

```lua filename="client.lua"
-- Toggle duty
exports['xt-duty']:toggleDuty()

-- Set duty state
exports['xt-duty']:setDuty(state)
```

### Duty States

| Value | Meaning |
| --- | --- |
| `0` / `false` | Off Duty |
| `1` / `true` | On Duty |
