## Usage

### Check Duty State

<Tabs items={['Client', 'Server']}>
<Tab>

```lua title="client.lua"
local duty = LocalPlayer.state.onDuty
```

</Tab>
<Tab>

```lua title="server.lua"
local duty = Player(source).state.onDuty
```

</Tab>
</Tabs>

### Toggle & Set Duty

Both exports are **client only**.

```lua title="client.lua"
-- Toggle duty
exports['xt-duty']:toggleDuty()

-- Set duty state
exports['xt-duty']:setDuty(state)
```

### Duty States

| Value | Meaning |
| --- | --- |
| `0` / `false` | Off Duty |
| `1` / `true` | On Duty |
