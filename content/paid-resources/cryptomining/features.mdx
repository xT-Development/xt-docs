# Features

### Cryptominer Customization

* Customize your internal cryptominer components based on  CPU limits, power requirements, etc. (CPU, GPUs, RAM, PSU)
* Add unlimited internal parts to your configurations
  * Developers can create as many parts as they'd like for players to customize their cryptominers
  * Internal parts contribute to power usage, hash rate, and power cost to keep the cryptominer running
  * CPUs, GPUs, RAM Sticks, and Power Supplies
* Mine Unlimited Crypto Types
  * Setup as many crypto types as you'd like from the config
  * Players can choose what crypto type to mine
  * Selected crypto type is used to pay for power consumption if enabled
* CPU Limitations
  * CPUs create internal "limits" on GPUs and RAM
  * CPUs limit the max RAM slots and the max RAM GB allowed on the "motherboard"
  * CPUs limit the max PCI-E slots available for GPUs on the "motherboard"

### User Logins

* Master logins created when cryptominer is initially placed down
* Master login gives users access to multiple extra settings for the cryptominer
  * Create unlimited basic user logins for other users
  * Modify basic user logins or delete them entirely from the cryptominer
  * Pickup or destroy the cryptominer at anytime
* Basic user logins can only toggle cryptominer power and modify the internal parts

### Hash Rates & Power

* Cryptominers have a total "hash rate" composed of the total output increase from all internal parts
* Cryptominers have a total "required power" composed of the required power for all internal parts
* Power supplies must meet the required power in order to power on the cryptominers
