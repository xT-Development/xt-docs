# Features

### General Features

* Admin menu to toggle the purge
* Starter loadouts when purge starts
* Scaleform for starting/ending the purge (configurable)
* Aggressive local peds. Fighting with other locals, and players
* Random air drops with an admin command to force spawn airdrops
  * Alerts ALL players
* Random city light flickering
* Ammo refill and loadout stations around the map
  * Max ammo per ammo type
  * Keep specific items when swapping loadouts
* Restore player inventories when the purge ends

### Airdrops

* Set max airdrops
* Set random time between airdrops
* Set expiration times (auto-cleanup)
* Configurable blips
* Random models
* Random spawn points
* Configurable smoke color
