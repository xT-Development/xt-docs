---
title: "Features"
---

The general idea of this resource is to be more of a feature that server owners and admins can toggle on/off for fun events for their server. You could use this as a base zombie handler for a apocalypse server as well, but you would need to create or purchase all the extra features outside of handling the base zombies. This does NOT have things such as hordes, as it does no manual spawning of peds; too much overhead for that.

### General Features

* Zombie menu to toggle zombies on/off, and toggle if zombies attack admins, or ignore them
* Synchronized zombies across all players
* Ability to create multiple zombie types with multiple different attributes
* Ability to search zombies you killed and receive loot
* Option to toggle power blackouts/flickering which randomly occurs

### Zombie Features

* Screen effect when attacked by zombies (configurable effects)
* Play attacked audio using open functions to trigger audio the way you prefer
* Different loot based on the type of zombies
* Configure multiple types of zombies based on models, movements, health, attack damage, hearing distances, headshots, and ability to explode with the option to change explosion types

### Configurations

* Open functions and events:
  * Toggle zombies (client & server, trigger other changes on toggle)
  * Add item (use any inventory)
  * Set blackout state (use any weather resource)
  * Play attacked audio (use any audio player from the client)
  * On attacked (trigger 3rd party resources when attacked)
