Everything your staff need in one panel: moderate players, read the logs, work the report
queue, hand out ranks, watch the map, and restart a resource - without leaving the game.

Every action is gated by rank before it runs and written to a searchable log that survives a
restart. Nothing the menu offers is decided by the client.

## The web portal

The same menu, in a browser - same permissions, same actions, same audit trail. It is a
**separate resource, included in the same bundle**, and it does nothing on its own: it
authenticates a browser and hands the request to this resource, which decides everything else.

<Callout type="info">
You do not need the portal to use the admin menu, and nothing on this page depends on it.
Everything portal-related in the configs sits inert until that resource is installed.
</Callout>
