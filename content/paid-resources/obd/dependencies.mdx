# Dependencies

| Dependency | Required |
| --- | --- |
| [ox_lib](https://github.com/CommunityOx/ox_lib/releases) | Required |
| [oxmysql](https://github.com/CommunityOx/oxmysql/releases) | Required |
| [Renewed-Lib](https://github.com/Renewed-Scripts/Renewed-Lib) | Required |
| [ox_inventory](https://github.com/CommunityOx/ox_inventory/releases) | Optional |

ox_inventory is only needed if you enable the physical scanner item. Access is job-only by default.
