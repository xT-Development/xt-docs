---
title: "Features"
---

* Server Logs (Public & Gang Crafting)
* Set Random Minigame Difficulties (ox_lib skill check)
* Refined Materials Ped (Enable / Disable)
* Gang crafting (Spawn models, add global models, or set ox_lib zones)
* Public Crafting (Spawn models, add global models, or set ox_lib zones)
* Gang Crafting Tables (Rep syncs to each table)
* Police can wipe gang crafting table rep back to 0
* Set custom items for each location you manually set
* Set custom items for each global model
